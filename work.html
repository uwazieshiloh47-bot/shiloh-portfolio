Portfolio Visitor Analytics

A live serverless API that records visits to this portfolio and returns the running count. Built deliberately slowly, one AWS service at a time, so I understand each piece before adding the next.

Project Goal

Follow a single HTTP request all the way through API Gateway, Lambda and DynamoDB, and be able to explain what every service does, what it costs, and how it is observed.

What I Built

  • Lambda handler in TypeScript, type-checked and tested
  • DynamoDB table with an atomic on-demand counter
  • HTTP API on API Gateway with exact-origin CORS
  • Least-privilege IAM: two actions on one table ARN
  • CloudWatch dashboard, alarms and structured logging
  • The whole stack in Terraform, validated by GitHub Actions CI

Where It Stands

Done and running. A request travels through API Gateway to Lambda to DynamoDB and the count persists, the portfolio itself now calls the API, and the hand-created resources were imported into Terraform so the stack is reproducible from code. The number below is this project, live:

Approximate portfolio visits: Loading… Usually one visit per browser tab session. This is an approximate total, not a count of unique people.

What I Learned

Bundling the AWS SDK into an ESM Lambda broke it at init — the SDK is CommonJS internally, and its require() calls became a shim that throws, so every route returned 500 before my handler ran. The fix was an esbuild banner defining a real require.

  • AWS
  • Terraform
  • TypeScript
  • GitHub Actions

Completed

My Portfolio

A responsive, six-page portfolio built from scratch with semantic HTML and custom CSS. It presents my background, skills, résumé, and project work through one consistent visual system.

Project Goal

I wanted to create a professional home for my work while also strengthening my front-end foundations before moving deeper into cloud engineering.

What I Built

  • A design-token system driving colour, type and spacing
  • An inline SVG sprite so logos inherit the page palette
  • Every colour pair measured against WCAG AA contrast
  • Motion and smooth scrolling gated behind prefers-reduced-motion

What I Learned

That CSS specificity is not intuition: defaults set on .project-tools li silently out-ranked every single-class brand rule, so no tag colour applied. Moving the defaults to the parent fixed it, because a value set on an element always beats an inherited one.

  • HTML5
  • CSS3
  • Accessibility
